GRAMMAR MATRIX OVERRIDE

Context-Free Grammar & Parse Tree Simulator

System Objective: Master formal language theory by constructing production rules for Context-Free Grammars (CFGs). Your job is to construct rules that accept valid language strings while rejecting invalid sequences.

⚡ 15 Randomised Challenges
⏱️ 30s Timed Runs
🌲 Real-time Parse Tree Generation
  1. Drag & Drop: Drag components (non-terminals, terminals, and ε) from the palette into the rule slots.
  2. Formulate Rules: Build production rules like S -> aSb, S -> ab, or S -> ε to match the target language.
  3. Submit Solution: Click Check Grammar to validate. Correct answers generate a Parse Tree showing the derivation!
  4. Manage Penalties: Wrong submissions deduct 1 Attempt (❤️) and penalize 5 Seconds.

Non-Terminals (S, E, T)

Variables replaced by strings of variables and terminals. S acts as the start symbol.

Terminals (a, b, c, d, (, ), 0, 1, ε)

Basic symbols forming string leaves. ε (epsilon) represents the empty string used to terminate recursion.

Production Rules (->)

Rewrite rules defining string generation. Format: [Non-Terminal] -> [Terminals/Non-Terminals/ε].

Parse Trees

A visual hierarchy showing step-by-step how terminal strings (or empty string steps via ε) are derived from the start symbol.

Created as an interactive computer science tool for Automata & Formal Language Theory.
